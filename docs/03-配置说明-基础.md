# 03 · 配置说明（基础）

给玩家的最小手册：**只讲功能开关、倍率与数值、改键**。
全部配置项（含排障项）见 `04-配置说明-完整.md`。

> 适用版本：Mod v2.9.0 四合一 / 游戏 2.2.4（build 25767968）

---

## 一、配置文件在哪

四个功能各有一份 ini，都放在**游戏根目录**（`HSLR.exe` 所在的文件夹。
Steam 里右键游戏 → 管理 → 浏览本地文件）：

| 配置文件 | 对应的功能 |
|---|---|
| `hslr-wait-hotkey.ini` | 待机快捷键（+ 四个功能的总开关） |
| `hslr-speed-hotkey.ini` | 战斗倍速 |
| `hslr-pinattr.ini` | 属性道具稳定加值 |
| `hslr-goldhand.ini` | 金之手 |

用**记事本**打开，改完**保存**即可生效；**不用重启游戏、也不用重新安装**。
以 `#` 开头的行是说明文字，删掉也不影响使用。

如果文件还不存在，说明该模块还没跑起来过 —— 启动一次游戏就会自动生成。

## 二、功能开关

### ① 分功能总开关（`hslr-wait-hotkey.ini` 的 `[features]` 段）

四个功能各有一个总闸，`1` = 开，`0` = 关：

```ini
[features]
wait = 1        ; 待机快捷键
speed = 1       ; 战斗倍速
pinattr = 1     ; 属性道具稳定加值
goldhand = 1    ; 金之手
```

关掉哪一项，对应功能就整体停用。**这是最常用的一条开关。**

### ② 游戏内的 Mod 开关

游戏主菜单 → **Mod 管理**里的勾选，是另一道独立开关。
总闸（上面）和游戏内开关**都要为开**，功能才生效。

> 改完游戏内勾选记得点 **「套用變更」**，否则重启后会恢复。

### ③ 金之手自己的开关（`hslr-goldhand.ini`）

```ini
[goldhand]
enable = 1      ; 1 = 开；0 = 关（关掉会自动还原成游戏原值）
```

## 三、待机快捷键 —— 改键

默认 **空格** 待机。编辑 `hslr-wait-hotkey.ini`：

```ini
[hotkeys]
space = wait
```

改成 F 键：把 `space = wait` 这一行删掉（或在行首加 `#` 注释），再加一行 `f = wait`。

可绑定的动作：

| 动作名 | 含义 |
| --- | --- |
| `move` | 移动 |
| `attack` | 攻击 |
| `skill` | 特殊技 |
| `magic` | 魔法 |
| `item` | 道具 |
| `status` | 状态 |
| `wait` | 待机 |

键名写法（小写）：

- 字母键：直接写 `f` `j` `k`
- 主键盘数字：`digit1` … `digit0`
- 小键盘：`numpad0` … `numpad9`
- 功能键：`f1` … `f12`
- 其它：`space` `enter` `tab` `escape` `up` `down` `left` `right`
  `leftshift` `rightshift` `leftctrl` …

> 同一个动作可以绑多个键（写多行）。**只在角色行动菜单里按才有效**，
> 菜单外无反应是刻意设计。

## 四、战斗倍速 —— 倍率与改键

编辑 `hslr-speed-hotkey.ini`。

### 倍率档位（`[options]` 段）

```ini
[options]
speed_steps = 1,2,5,10
```

按 `+` 升档、`-` 降档，到两端停住。默认四档：1x → 2x → 5x → 10x。

- 最高只到 5 倍：`speed_steps = 1,2,5`
- 再加 20 倍：`speed_steps = 1,2,5,10,20`

> 对话与剧情演出期间会自动让路（不加速、不跳过对话），这是设计如此。

### 改键（`[hotkeys]` 段）

左边是键名，右边是动作（`speed_up` 加速 / `speed_down` 减速）：

```ini
[hotkeys]
equals = speed_up          ; 主键盘 +
minus = speed_down         ; 主键盘 -
numpadplus = speed_up      ; 小键盘 +
numpadminus = speed_down   ; 小键盘 -
```

不想要哪组键，把那一行删掉即可。

## 五、属性道具稳定加值 —— 固定数值

编辑 `hslr-pinattr.ini` 的 `[options]` 段。
作用：吃「之源 / 之魂」时，把游戏原本的**随机加值固定成指定数字**。

```ini
[options]
pin_items = 224:5,225:5,226:5,227:5,280:15,281:15,282:15,283:15,290:10
```

格式为 `道具ID:数值`，逗号分隔。默认值就是各道具随机范围的上限（一次吃到满）。

- 想固定成 3 点：把 `224:5` 改成 `224:3`
- 不想干预某个道具：把它从这一行删掉
- 只想管力之源：`pin_items = 224:5`

道具对照：

| ID | 道具 | ID | 道具 |
| --- | --- | --- | --- |
| 224 | 力之源 | 280 | 力之魂 |
| 225 | 禦之源 | 281 | 禦之魂 |
| 226 | 魔之源 | 282 | 魔之魂 |
| 227 | 速之源 | 283 | 速之魂 |
| | | 290 | 霸之魂 |

> **绝不误伤**：只影响上面列出的道具。回血药、装备词条、五抗之源、聖之魂
> 以及其他一切随机效果都保持原样。

## 六、金之手 —— 数值

编辑 `hslr-goldhand.ini` 的 `[goldhand]` 段：

```ini
[goldhand]
enable = 1
hit_ratio = 100
expend = 1
kill_gold_ratio = 10
```

| 项目 | 含义 | 原版值 | 说明 |
| --- | --- | --- | --- |
| `hit_ratio` | 命中率（%） | 90 | 填 `90` 恢复原版 |
| `expend` | 气力格数 | 金之手 3 / 高级 2 | 填 `3` 恢复原版 |
| `kill_gold_ratio` | 杀敌金钱倍数 | 1 | `1` = 原版；默认 `10`；上限 `100000` |

> `kill_gold_ratio` 只作用于**战斗击杀结算**的金币；
> 商店买卖、任务奖励、卡牌小游戏都不受影响。

---

## 七、改错了怎么办

把改动的那几行恢复成本文中的默认值，保存即可。

实在改乱了：**直接删掉那份 ini**，重启一次游戏就会重新生成默认的。
