# 04 · 配置说明（完整）

逐条列出全部配置项。**只想改开关 / 倍率 / 键位的话，看 `03-配置说明-基础.md` 就够了**；
本文包含排障与内部项，平时不需要动。

> Mod v2.9.0 / 游戏 2.2.4（build 25767968）
>
> 通用约定：
> - 所有 ini 都在**游戏根目录**，用记事本改，保存即生效（热重载，不用重启）。
> - 布尔值接受 `1/0`、`true/false`、`on/off`、`yes/no`（大小写不敏感）。
> - `#` 或 `;` 开头的行是注释。
> - 键不存在 = 用默认值，**不是错误**（老配置文件因此保持兼容）。
> - ini 编码应为 **UTF-8（带 BOM）**；行尾 CRLF。工具与 DLL 双方都按这个约定读写。

## 1. `hslr-wait-hotkey.ini` — 伞形（主 Mod）

伞形是唯一入口。这份 ini 除了自己的键位，还承载**四个功能的总开关**。

### 1.1 `[hotkeys]` — 键位 → 动作

```ini
[hotkeys]
space = wait
```

格式：`<键名> = <动作名>`。一个动作可以绑多个键（写多行）。

| 动作名 | 含义 |
|---|---|
| `move` | 移动 |
| `attack` | 攻击 |
| `skill` | 特殊技 |
| `magic` | 魔法 |
| `item` | 道具 |
| `status` | 状态 |
| `wait` | 待机 |

键名（小写）：字母直接写（`f`/`j`/`k`）；主键盘数字 `digit1`…`digit0`；
小键盘 `numpad0`…`numpad9`；功能键 `f1`…`f12`；
其它 `space` `enter` `tab` `escape` `up` `down` `left` `right`
`leftshift` `rightshift` `leftctrl` `leftalt` …

> 只在**角色行动菜单确认可操作**时响应；菜单外按键无反应，这是刻意设计。

### 1.2 `[options]` — 行为选项

| 键 | 默认 | 说明 |
|---|---|---|
| `require_no_modifier` | `1` | 按住 Shift / Ctrl / Alt / Win 时不触发。避免与游戏原生组合键冲突 |
| `verbose_log` | `0` | 每次触发都写详细日志。排障时临时改 `1` |
| `force_enable` | `0` | `1` = 忽略游戏内的 Mod 管理开关，强制生效。**仅本地排障**，正式订阅保持 `0` |
| `mod_id` | `待机快捷键` | 游戏 Mod 管理里那条记录的 `modId`。DLL 靠它认游戏内开关。改包名时要同步改这里 |
| `mod_id_approach` | `hslr-auto-move` | 自动接近功能对应的 Mod 条目 ID（该条目关闭时自动接近不生效） |
| `ap_path_range` | `6` | 自动接近计算路径时的移动范围兜底值（1–99，仅在游戏范围数据为空时用到） |
| `rva_mode` | `auto` | 运行时重定位模式，见 1.4 |
| `rva_window` | `0x40000` | 锚点搜索窗口半宽（十六进制）。仅排查用 |
| `rva_shot` | `0` | 仅 `selftest` 模式：把查询锚点人为偏移这么多字节 |

### 1.3 `[features]` — 分功能总开关

`1` = 开，`0` = 关。**这是四个功能的总闸**：关掉后该功能整体停用，
游戏内 Mod 开关和卫星自己的 ini 都不再单独影响它。

```ini
[features]
wait = 1        ; 待机快捷键（伞形本体）
approach = 1    ; 自动接近（已废弃）
speed = 1       ; 战斗倍速（卫星，跨文件读取本段）
pinattr = 1     ; 属性道具稳定加值（卫星，跨文件读取本段）
goldhand = 1    ; 金之手（卫星，跨文件读取本段）
```

三个卫星都会**跨文件**来读伞形这份 ini 的这一段；文件缺失或键缺失一律**视为开**。

> `approach` **已废弃**：源码与地址常量仍保留、且纳入指纹校验，但功能不再维护。
> 它还需要一个额外的游戏内 Mod 条目；没有该条目时，这个开关开着也不会有任何效果。

### 1.4 运行时重定位（`rva_mode` / `rva_window` / `rva_shot`）

设计说明见 `01-设计与架构.md` 第 6 节，这里只列可用值：

| 值 | 行为 |
|---|---|
| `auto` | **默认**。构建哈希命中白名单 → 恒等映射（零开销）；不认识 → 窗口搜索 |
| `native` | 强制使用源码里的原值（调试基准用） |
| `adaptive` | 强制窗口搜索（即使构建已知） |
| `selftest` | 强制窗口搜索，并把查询锚点人为偏移 `rva_shot` 字节 —— 用来验证「锚点过时后能否找回」 |

排查时看日志里 `reloc:` 开头的行：

```
reloc: NATIVE (build known; 45 anchors used as recorded, zero scan)
reloc: ADAPTIVE engine; 45 anchors; window=0x40000; stale-anchor offset=+0
reloc: 43/45 anchors relocated; 2 point(s) disabled; total candidate hits=57
reloc FAIL <名字> anchor=0x... hits=0|N        ← 某个点没找回，对应功能已降级
```

## 2. `hslr-speed-hotkey.ini` — 战斗倍速

### 2.1 `[hotkeys]`

格式：`<键名> = speed_up | speed_down`。默认主键盘与小键盘的 `+` / `-` 都绑。

```ini
equals = speed_up
minus = speed_down
numpadplus = speed_up
numpadminus = speed_down
```

### 2.2 `[options]`

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | `1` | 本功能总开关（`0` = 停用并把当前档位收回 1x） |
| `speed_steps` | `1,2,5,10` | 档位序列，逗号分隔，**升序**，上限 = 最后一项 |
| `require_no_modifier` | `1` | 按住 Ctrl / Alt / Win 时不触发。**Shift 放行** —— 主键盘 `+` 本身就要 Shift 配合，不能因此拒掉加速键 |
| `dialogue_force_1x` | `1` | 对话/演出期间主动把速度压回 1x 的兜底保险 |
| `guard_reassert` | `1` | 进战斗 / 读档 / 切场景后自动恢复设定档位 |
| `verbose_log` | `0` | 每次切档/恢复都写日志。排查用 |
| `trace_gset` | `0` | GSET 写入者追踪钩：钩住官方 `Global.SetGameSpeed`，记录每次写入的值与调用方。**只记录不干预**，纯排查设施 |
| `force_enable` | `0` | 忽略游戏内 Mod 开关（本地预览用） |
| `mod_id` | `战斗倍速快捷键` | 对应的 Mod 条目 ID |

## 3. `hslr-pinattr.ini` — 属性道具稳定加值

### 3.1 `[options]`

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | `1` | 本功能总开关 |
| `pin_items` | 见下 | 要干预的道具 → 固定加值 |
| `attr_types` | `9,12,14,15` | 允许干预的属性类型（EFightAttrType 序号）。最后一道防误伤闸门 |
| `verbose_log` | `0` | 逐对象写详细日志。排查用 |
| `force_enable` | `0` | 忽略游戏内 Mod 开关（本地预览用） |
| `mod_id` | `属性道具稳定加值` | 对应的 Mod 条目 ID |

**`pin_items`** 格式为逗号分隔的 `道具ID:数值` 对。只有列出的道具会被干预，
没列的（回血药、装备词条、五抗之源……）完全不受影响。

```ini
pin_items = 224:5,225:5,226:5,227:5,280:15,281:15,282:15,283:15,290:10
```

| ID | 道具 | ID | 道具 |
|---|---|---|---|
| 224 | 力之源 | 280 | 力之魂 |
| 225 | 禦之源 | 281 | 禦之魂 |
| 226 | 魔之源 | 282 | 魔之魂 |
| 227 | 速之源 | 283 | 速之魂 |
| | | 290 | 霸之魂 |

**`attr_types`** 是 EFightAttrType 的序号白名单：

| 值 | 属性 |
|---|---|
| 9 | 防御 |
| 12 | 速度 |
| 14 | 物理攻击 |
| 15 | 魔法攻击 |

> 刻意**不含 5（HP）**：回血药走同一段代码，把 HP 加进来会让「回血」也变成固定值，
> 那是误伤。这是一个必须保持的约束，不是可自由调整的选项。

## 4. `hslr-goldhand.ini` — 金之手

### 4.1 `[goldhand]`

金之手用的是**数据钳值**方案：游戏表加载后，把「金之手 / 高级金之手」的目标值
直接改写为下面两项。不做运行时挂钩，因此零 MinHook 开销。

| 键 | 默认 | 原版值 | 说明 |
|---|---|---|---|
| `enable` | `1` | — | 本功能总开关（`0` = 整体停用，并自动还原为游戏原值） |
| `hit_ratio` | `100` | `90` | 目标命中率（%）。游戏会从命中率里减去对方闪避，本 Mod 在内部把值放大到足以抵消，界面显示的仍是 100%。回原版写 `90`。取值夹在 `[0,100]` |
| `expend` | `1` | 金之手 3 / 高级 2 | 目标气力格数。回原版改回 `3`（高级会按各自原值还原，见日志）。取值夹在 `[0,9]` |
| `steal_always` | `1` | — | `1` = 必定偷到（把道具表的 `GetRatio` 钳高，使偷窃判定必过）；`0` = 保持游戏原判定（可能「命中但偷不到」） |
| `kill_gold_ratio` | `10` | `1` | 杀敌金钱倍数。战斗击杀结算时把该次入账金币 × N。`1` = 关闭。取值夹在 `[1, 100000]` |
| `verbose_log` | `0` | — | 逐对象钳值日志。排查用 |
| `trace` | `0` | — | 装只读探针，把命中/偷窃判定的运行时真值写进日志（临时钩 4 个游戏函数，**只读不改状态**）。排查用 |
| `force_enable` | `0` | — | 忽略游戏内 Mod 开关（本地预览用） |
| `mod_id` | `待机快捷键` | — | 对应的 Mod 条目 ID（与主 Mod 联动，匹配不到时自动回退内置 ID） |

> **`kill_gold_ratio` 的作用范围**：只影响「**战斗击杀结算**」这一条路径。
> 商店买卖、任务奖励、事件、卡牌小游戏一律不受影响 ——
> 这是通过定位「纯战斗结算」写点做到的，不是靠数值判断。
>
> 上限 100000 是有意设的：金币字段是 32 位有符号整数，
> 倍数写得太大可能在累加时溢出。

## 5. 常见问题排查顺序

1. **先看 `[features]` 段**：四个功能是不是都为 `1`？
2. **再看游戏内 Mod 开关**：Mod 列表里勾选了吗？点过「套用變更」了吗？
3. **看日志**：游戏根目录的 `hslr-*.log`。
   - 没有日志文件 → 模块没跑起来（装错位置 / 被杀软隔离 → 看 `Mod DLL path` 那行）
   - 日志停在 `GameAssembly.dll ... is the Mod DLL really inside the game directory?` → 安装位置不对
   - 日志有 `reloc FAIL` → 对应功能被降级，见 1.4
4. **跑一次环境自检**：`manage.cmd` 选 `2`（或 `installer.ps1 doctor`）
5. 仍不行：把 `hslr-*.log` 整个发出来。
