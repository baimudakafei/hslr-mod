# 幻世录重置版 · 待机快捷键 Mod（v2.9.0 四合一）

在角色行动菜单里按**空格**直接「待机」，不用再拿鼠标去点按钮。
其他时候游戏按键完全不受影响（不会抢键、不改游戏原生存档/快捷键）。

**v2.0.0 起多个功能合到一个 Mod 里**，共用游戏内「待机快捷键」这一个开关：

| 功能 | 默认操作 | 说明 |
|---|---|---|
| 待机快捷键 | 空格 | 行动菜单里一键待机（原 v1.x 全部功能） |
| 战斗倍速快捷键 | 主键盘/小键盘 `+` / `-` | 1x → 2x → 5x → 10x 循环切档，右下角常显当前档位 |
| 属性道具稳定加值 | 自动 | 用「之源 / 之魂」时加值固定到上限（224~227→5，280~283→15，290→10） |
| 金之手（偷窃强化） | 自动 | 用「金之手」偷窃时气力只需 1 格、命中率 100%（偷完为止） |
| 杀敌金钱倍数 | 自动 | 战斗击杀敌人获得的金币 ×N（**默认 10 倍**，可在 `hslr-goldhand.ini` 改） |

想单独停用某一项：改**游戏根目录**对应配置文件里的 `enable = 1` 为 `0`，保存即生效：

- 停用倍速 → `hslr-speed-hotkey.ini`（停用瞬间档位自动收回 1x）
- 停用加值 → `hslr-pinattr.ini`（也可直接编辑 `pin_items` 精确控制哪些道具被干预）
- 停用金之手 / 调杀敌金钱倍数 → `hslr-goldhand.ini`（`kill_gold_ratio = 10` 改小改大，`1` = 原版）
- goldhand 的 `trace` 调试探针自 v2.7.1 起**默认关闭**（`trace = 1` 才会开启，仅排障用）
- 待机快捷键本身没有 enable 项，删掉 `[hotkeys]` 里的键位行即等效停用

- 适配：游戏 **2.2.4**（Steam build 25767968）/ Windows 10、11 x64
- **v2.9.0 新增「免版本跟进」**：官方再做小更新（只挪动代码位置、没改我们用的函数）时，
  四个 Mod 会**自动**在附近把真实地址找回来，通常不再需要作者重新发布就能继续用。
  （构建没变时行为与 v2.8.0 完全一致，零额外开销。）
- 无需安装任何运行库：管理工具用的是 Windows 自带的 PowerShell

## 一、安装

### 方式 A：Steam 创意工坊订阅（推荐，零操作）

1. 在本 Mod 的 Steam 创意工坊页面点「订阅」，等 Steam 下载完成。
2. 启动游戏 → 主菜单左下 **创意工坊 → 启动本 Mod**（勾选后记得点「套用變更」）。
3. 完成。**v2.5.4 起订阅链路完整支持全部四个功能**，不需要任何手动安装步骤。

> 升级提示：从旧版本升级后如果游戏内 Mod 列表版本号没变，先完全退出游戏再进
> （Steam 后台更新可能延迟）；个别情况下需要在游戏内把本 Mod 关掉再开启一次。

> 如果订阅后个别功能仍不生效（比如空格待机没反应），用下面的**方式 B 兜底**，
> 一分钟就能装好；欢迎把情况留言反馈给作者。

### 方式 B：手动安装（兜底，3 步）

**1）先完全退出游戏**（含 Steam 里的启动器）。

**2）确认工具文件夹的位置**，两种入口任选其一：

- **订阅玩家**：直接进创意工坊条目所在文件夹。每个人 Steam 库路径不同，
  形如（注意是 `workshop\content`，游戏本体在 `steamapps\common`）：

  ```
  X:\Steam\steamapps\workshop\content\4030150\3802488917
  ```

  找法：先在 Steam 库里右键游戏 → 属性 → 已安装文件 → 浏览，打开游戏所在的
  库根目录（`...\steamapps\common\幻世錄 Remake` 的上两级 `steamapps\`），
  旁边同级就有 `workshop\content\4030150\3802488917`。

- **下载包玩家**：把压缩包解压到游戏的 Mod 目录，也就是这个位置：

  ```
  C:\Users\<你的用户名>\AppData\LocalLow\UserJoy\HSLR\MODS\待机快捷键\
  ```

  怎么快速找到它：按 `Win + R`，粘贴下面这行回车，就打开了 MODS 文件夹，
  再看有没有 `待机快捷键` 文件夹（没有就自己新建一个同名的，然后解压进去）：

  ```
  %USERPROFILE%\AppData\LocalLow\UserJoy\HSLR\MODS
  ```

  解压完成后，`待机快捷键` 文件夹里应该能看到 `mod.json`、`preview.png`、
  `installer.ps1`、`manage.cmd`、`settings.ini`、`使用说明.md`、`d3d11.dll`
  以及 `mod-speedkey.dll`、`mod-pinattr.dll`、`mod-goldhand.dll`
  （后三个是倍速/加值/金之手的卫星模块）——这就是完整状态。

  > **为什么解压到这里？** 这个文件夹本身就是游戏内 Mod 的「条目」，
  > 压缩包里自带的 `mod.json` 是它的身份卡（写着 modId、名字、版本）。
  > 游戏只扫描这个位置，条目到位后游戏 Mod 列表里立刻能看到本 Mod。

**3）双击 `manage.cmd`，选 `3`（安装）。**

这一步做三件事：把 `d3d11.dll`（待机，主模块）和 `mod-speedkey.dll`（倍速）、
`mod-pinattr.dll`（加值）、`mod-goldhand.dll`（金之手）一起放进**游戏根目录**
（放在别处不会被加载，所以这一步必须做一次）；同时同步键位配置；并把旧版独立的
倍速/加值 Mod 条目自动移出 MODS 文件夹（**只移动到旁边的备份文件夹，不删除**）。

装完启动游戏：主菜单 → **Mod 管理 → Mod List → 勾选本 Mod → 点「套用變更」**。
（不点「套用變更」的话，重启游戏前不会生效。）

进战斗、角色行动菜单出现后按空格即待机。

> **升级提醒**：Mod 出新版本后，手动安装的玩家**必须重跑一次安装（选 3）**，
> 否则游戏根目录里还是旧版 DLL（自检会提示「与工具不一致（需重新安装）」）。

## 二、改键（空格 → 别的键）

本 Mod 的所有配置都在**同一个文件夹里的 `settings.ini`**，用记事本打开就能改：

```ini
[hotkeys]
space = wait      ← 就是这一行：左边是键，右边是动作（wait=待机）
```

**把待机换成 F 键的完整示例：**

```ini
[hotkeys]
# space = wait    ← 注释掉或删掉这一行
f = wait          ← 加上这一行
```

常用键名对照：

| 类型 | 写法 |
|---|---|
| 字母键 | `f` `j` `k` …（直接写小写字母） |
| 主键盘数字 | `digit1` `digit2` … `digit0` |
| 小键盘 | `numpad0` `numpad1` … `numpad9` |
| 功能键 | `f1` `f2` … `f12` |
| 其它 | `space` 空格、`enter` 回车、`tab`、`escape`、方向键 `up` `down` `left` `right` |

更多用例（数字、小键盘、功能键、给攻击/魔法等绑键）都写在 `settings.ini`
的 `[hotkeys]` 段注释里，照着抄即可。**改完保存，重新跑一次安装（选 3）生效。**

> 小技巧：重装后想临时试键，也可以直接改游戏根目录里的
> `hslr-wait-hotkey.ini`，存盘立刻生效、不用重装——但下次用工具重装时会被
> `settings.ini` 覆盖，想长期生效就两边改成一样。

> **v2.9.0「免版本跟进」**：游戏根目录 `hslr-wait-hotkey.ini` 的 `[options]` 段
> 新增三个可选项（`rva_mode` / `rva_window` / `rva_shot`），**默认全部注释掉**，
> 日常不需要动 —— 官方小更新后 Mod 会自动生效。只有在排障时才按需打开。

## 三、路径配置（一般不用动）

`settings.ini` 的 `[paths]` 段有三个路径，**全部留空 = 自动检测**，
自动检测失败（Steam 装在特殊位置、多游戏库等）才需要手动填：

```ini
[paths]
game  =    ← 游戏根目录（HSLR.exe 所在文件夹）
mods  =    ← 游戏 Mod 目录（LocalLow 下的 MODS 文件夹）
steam =    ← Steam 库根目录（帮自动发现指路，如 D:\SteamLibrary）
```

三项都有详细的中文注释和填写示例，照着注释填即可。

## 四、文件都是干什么的

| 文件 | 作用 | 能不能动 |
|---|---|---|
| `mod.json` | **本 Mod 的身份卡**（modId / 名字 / 版本 / 说明）。游戏只认它，缺了整个文件夹会被游戏忽略 | 别删、别改名 |
| `preview.png` | 游戏 Mod 列表里的封面 | 可换，同名覆盖 |
| `d3d11.dll` | 待机功能本体（主模块），安装时复制到**游戏根目录**；它还会在游戏启动时自动装载下面三个卫星模块 | 别删 |
| `mod-speedkey.dll` | 战斗倍速卫星模块，安装时复制到**游戏根目录** | 别删 |
| `mod-pinattr.dll` | 属性道具稳定加值卫星模块，安装时复制到**游戏根目录** | 别删 |
| `mod-goldhand.dll` | 金之手（偷窃强化）卫星模块，安装时复制到**游戏根目录** | 别删 |
| `installer.ps1` | 安装/卸载/自检主程序（PowerShell 写的） | 别删 |
| `manage.cmd` | 双击入口，负责以 PowerShell 身份调用上面那个脚本 | 别删 |
| `settings.ini` | 你的配置：路径 + 键位 | 随便改 |
| `使用说明.md` | 就是本文件 | 随便 |
| `mod\` | 工具用的素材（封面原图），不影响游戏 | 可留可删 |
| `backup\` | 卸载/升级时自动生成的备份（装过才有） | 可删 |

## 五、用不了？先自检

双击 `manage.cmd` 选 **2（环境自检）**，它会逐项检查并直接告诉你怎么修：

- 游戏版本不支持 → 本 Mod 只适配 2.2.4（build 25767968），等 Mod 更新
- 游戏目录没找到 → 用 `setgame` 手动指路（或填 `[paths] game`）
- 游戏内看不到开关 → 只解压没运行安装；Mod 目录里少了 `mod.json`（见下一节）；或没点「套用變更」
- **订阅玩家个别功能不生效** → 先确认游戏内 Mod 列表里版本号是 v2.9.0；
  旧版本（v2.5.3 及更早）订阅后确实需要手动安装。仍不行就跑一次方式 B 兜底，
  或把游戏根目录里的 `hslr-*.log` 发给作者
- 按了没反应 → 先确认是在**角色行动菜单里**按的（菜单外无反应是设计如此）
- **官方更新后日志出现 `reloc: ADAPTIVE engine`** → 这是 v2.9.0 的「免版本跟进」在自动
  找地址，属正常现象；若某个功能仍失效，日志里会有该点的 `reloc FAIL …` 行，发给作者即可
- 杀毒软件提示 / DLL 消失 → 本 Mod 是未签名的个人作品，个别杀软可能误报。
  在杀软里把游戏目录加入信任（白名单），然后重新运行安装

### 游戏 Mod 列表里看不到本 Mod（或按空格没反应）？

先查这一条：**`待机快捷键` 文件夹的根目录下必须有 `mod.json`。**
游戏的规则是——**子文件夹里没有 `mod.json` 就整个目录被忽略**（游戏日志里写作
「忽略無效 MOD 目錄」），Mod 列表随即变空，快捷键自然不生效。

`mod.json` 是本 Mod 的身份卡，**不要删、不要改名、不要移走**。
整理目录时，把它和 `installer.ps1` 等文件一起平铺在 `待机快捷键\` 根目录是**允许的**
（本包的默认布局就是这样），根目录最少要保留：

```
待机快捷键\
  mod.json           ← 千万别动（游戏靠它认人）
  preview.png        ← 封面
  installer.ps1      ← 安装/自检
  manage.cmd         ← 双击入口
  settings.ini       ← 你的配置
  d3d11.dll          ← 待安装的主模块（待机）
  mod-speedkey.dll   ← 待安装的卫星模块（倍速）
  mod-pinattr.dll    ← 待安装的卫星模块（加值）
  mod-goldhand.dll   ← 待安装的卫星模块（金之手）
```

万一已经丢了：**重新跑一次安装**（双击 `manage.cmd` 选 3）就会重建它，
然后进游戏在 Mod 管理里重新勾选一次即可恢复。

另外：在游戏里把本 Mod 关掉（或勾了没点「套用變更」）同样会让快捷键失效 —— 这是设计如此。

### 双击 manage.cmd 报「'aller.ps1' 不是内部或外部命令」？

这是启动器文件被改坏（编码或换行变了）导致的，v1.2.2 之前的包有问题，**请重新下载最新包**。
急着用的话，可以不经过启动器，直接运行主程序：

1. 在本文件夹里，右键 `installer.ps1` → **使用 PowerShell 运行**
2. 或者：在该文件夹的地址栏里输入 `powershell -ExecutionPolicy Bypass -File installer.ps1 doctor` 回车
3. 自检会自动把坏掉的 `manage.cmd` 修好，之后双击就正常了

再不行：自检页面截图 + 游戏根目录里的 `hslr-wait-hotkey.log` 一起发给作者。
日志里记录了 Mod 的安装位置、游戏版本校验结果、按键与菜单状态的判定原因，
作者看一眼日志就能定位大多数问题。想让日志更详细（记录每次按键与菜单判定），
把游戏根目录里 `hslr-wait-hotkey.ini` 的 `verbose_log` 改成 1，保存即生效。

## 六、卸载

双击 `manage.cmd` 选 **4（卸载）**。DLL 与配置会先备份到本文件夹的 `backup\`
里再移除，游戏根目录恢复原状；游戏内 Mod 条目会一起移走
（不想动条目就在命令后加 `-KeepModEntry`）。
